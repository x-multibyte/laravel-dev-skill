# Laravel Documentation Versions

This directory contains Laravel documentation for multiple versions.

## Available Versions

- **10.x** - 24 topic files available
- **11.x** - 24 topic files available
- **12.x** - 24 topic files available

## Switching Versions

To switch between versions, use the version manager:

```bash
python scripts/version_manager.py --set-current 12.x
```
